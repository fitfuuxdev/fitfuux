## Запуск

Из папки проекта:

```powershell
python -m http.server 4182 --bind 127.0.0.1
```

Открыть: **http://127.0.0.1:4182/**

Нужен локальный сервер, а не двойной клик по HTML: браузеры не загружают ES-модули и локальные шрифты по `file://`.

## Как проверять перед запуском

1. Запустите сервер и откройте каждую страницу из таблицы.
2. Проверьте на компьютере и на телефоне:
   - бургер-меню открывается и закрывается;
   - ссылки в шапке и подвале ведут туда, куда должны;
   - кнопки «Написать», Telegram и телефон работают;
   - блоки появляются при прокрутке без рывков;
   - на телефоне нет горизонтального скролла;
   - фото загружаются (при медленной сети сначала видна заглушка).
3. На каждой странице есть 3D-сцена:
   - её можно перетащить мышью или пальцем;
   - при прокрутке она двигается;
   - при `prefers-reduced-motion` показывается статичный кадр;
   - при отключённом WebGL остаётся статичный кадр, страница не падает.
4. Контакты:
   - Telegram — [@Fitfuux](https://t.me/Fitfuux);
   - телефон — +7 995 258-57-87;
   - СБП — получатель Алексей;
   - форма собирает сообщение, копирует его и открывает Telegram (бэкенда нет — данные никуда не уходят).
5. Проверьте консоль: ошибок и упавших запросов быть не должно.
6. Для локальной проверки мобильной версии удобно использовать DevTools → Toggle device toolbar.

Автоматические проверки, которые уже прошли: все внутренние ссылки и якоря, адаптивность на 320/390/768/1024/1440 px, отсутствие ошибок консоли, WebGL-drag, fallback без WebGL, reduced-motion, фильтры портфолио, меню, форма, копирование, slider, axe-core (0 нарушений WCAG A/AA на всех страницах).

## Публикация и домен

Сайт уже опубликован на GitHub Pages: **https://fitfuuxdev.github.io/fitfuux/**.

Если меняете домен, замените адрес в одном месте:

```js
// scripts/site.mjs
export const SITE = 'https://fitfuuxdev.github.io/fitfuux';
```

Затем пересоберите страницы. Для минификации один раз установите пакеты:

```powershell
python -m pip install csscompressor rjsmin
python scripts/minify.py
node scripts/build.mjs
```

Тогда canonical, Open Graph, sitemap и JSON-LD будут указывать на ваш домен.
Если меняете контакты или цены, ищите их в `scripts/site.mjs` и `scripts/content-*.mjs`, затем повторите две команды выше.

Готовые страницы — обычный HTML/CSS/JS. Их можно править и напрямую, но после правок исходных CSS/JS нужно заново запустить `scripts/minify.py`, потому что страницы подключают минифицированные файлы.

Загружайте в интернет **содержимое папки** проекта (не саму папку) на GitHub Pages, Netlify, Vercel или обычный хостинг. `.nojekyll` уже есть для GitHub Pages. Включите gzip/brotli на хостинге — статика сожмётся в несколько раз.

## Что внутри

- 11 статических страниц, общий фирменный каркас, у кейсов — собственные палитры, шрифты, ритм и 3D-модели.
- 11 собственных WebGL-сцен Three.js: бренд-блок, слои, карусель, орбита, диски, бумажный самолёт, чашка, гантель, неоновая геометрия, флакон, клош.
- Авто-вращение 360°, вращение мышью/пальцем, стрелки клавиатуры, плавное затухание, пауза вне экрана.
- Ленивая загрузка 3D и фото, WebP + `srcset`, локальные subset-шрифты, CSS/JS в минифицированных версиях.
- Fallback: если WebGL или анимации отключены, показывается прозрачный статичный рендер модели.
- Все изображения — локальные файлы в `assets/img/`, OG-обложки — в `assets/og/`, логотип и favicon — в `assets/brand/`.
- Форма обратной связи не отправляет данные на сервер: она собирает текст и открывает Telegram.
